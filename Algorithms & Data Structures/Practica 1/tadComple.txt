El TAD Complejo es un tipo de dato el cual esta representado por dos enteros donde uno es la parte Real y el otro la parte Imaginaria.

Y tiene el sig. conjunto de operaciones

crearComplejo; Z  X Z  -> Complejo


partReal: Z  X Z-  ->  Z
partReal: Complejo ->  Z

/* Pre-condición: r ha sido creado. */

partImagi: Z  X Z  ->  Z
partImagi: Complejo ->  Z

/* Pre-condición: r ha sido creado. */

sumar: Complejo X Complejo -> Complejo
/* Pre-condición:  r1 y r2 han sido creados. */

restar: Complejo X Complejo -> Complejo
/* Pre-condición:  r1 y r2 han sido creados. */

multiplicar: Complejo X Complejo -> Complejo
/* Pre-condición:  r1 y r2 han sido creados. */ 

dividir:  Complejo X (Complejo -{0})-> Complejo
/* Pre-condición:  r1 y r2 han sido creados. y r2 <> 0*/

//Hacer una copia de un Complejo.
copia: Complejo -> Complejo
